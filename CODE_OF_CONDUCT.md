# Community conduct

Be respectful, specific and constructive. Critique code and decisions rather than people. Harassment, threats, discriminatory abuse, doxxing, and publishing private information or credentials are not acceptable.

Maintainers may edit or remove abusive content and restrict participation when necessary. These expectations apply in repository issues, pull requests, discussions and other project-maintained spaces. Maintainers are held to the same standards.

Report conduct concerns privately through the maintainer's [GitHub profile contact options](https://github.com/gsaintskad). If there is no private contact available, open a neutral issue asking for one without disclosing personal details. Security vulnerabilities must instead follow SECURITY.md.
